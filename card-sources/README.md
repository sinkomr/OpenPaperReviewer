# Where each card's sources support it

Each file here belongs to the checklist card at the same path under [`plugin/skills/open-paper-reviewer/references/checklists/`](../plugin/skills/open-paper-reviewer/references/checklists/). For every source the card lists, it records the access the card's author reached and where in the source the support for the card's items is.

Reviews do not read these files. They are the record that every benchmark was opened, kept outside the plugin so that a review does not pay to load them. `scripts/check_card.py` checks each card together with its file here.
