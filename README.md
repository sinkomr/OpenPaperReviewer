# Posted reviews

This branch holds reviews of publicly available papers made with the [OpenPaperReviewer](https://github.com/sinkomr/OpenPaperReviewer) method. The method, the skill and the prompts are on the [`main` branch](https://github.com/sinkomr/OpenPaperReviewer/tree/main).

**Read these as drafts.** Each review is AI-assisted. Each one records the model, reasoning effort and prompt that produced it, how many of its own sources were verified, and what a person checked. A posted review has passed an automatic format check and a maintainer's read for the posting rules. Nobody has vouched for its conclusions.

A review assesses a paper's claims and evidence. It says nothing about the paper's authors.

- To post a review, or to correct or withdraw one, see [`CONTRIBUTING.md`](https://github.com/sinkomr/OpenPaperReviewer/blob/main/CONTRIBUTING.md).
- If your paper is reviewed here and you want to respond, [open an issue](https://github.com/sinkomr/OpenPaperReviewer/issues/new/choose) with the "Author response" template.

Each review lives at `<paper-id>/<paper-version>/<reviewer>-<date>/`. Start with `06_synthesis.md`. This list is in order of paper and date and is not a ranking.
